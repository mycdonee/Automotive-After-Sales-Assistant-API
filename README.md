# automotive-after-sales-assistant-api
FastAPI-based backend prototype for automotive service text retrieval, issue classification, and information extraction.

## Current status

This project is under active development.

## Planned features

- REST API health check
- Similarity-based retrieval of automotive service records
- Service issue classification
- Keyword and component extraction
- Pydantic request and response validation
- Automated tests with pytest
- Interactive OpenAPI documentation

## Disclaimer

This is an educational software prototype and does not provide vehicle
diagnosis, repair instructions, or safety advice.
